# BIA Hackathon 2026 - Boston Analytics

Gen AI Hackathon Project repository.

## Setup Instructions

### 1. Setup
```powershell
uv sync   # creates .venv (Python 3.13) and installs everything from uv.lock
```

### 2. Run
```powershell
uv run bia-hackaton-2026
uv add <package>   # add a dependency
```
